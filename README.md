# Excel

## Описание задания

Набор данных содержит информацию о вакансиях в сфере IT: идентификатор вакансии, технологию, название позиции, компанию, город, зарплатную вилку, требуемый опыт, тип занятости, график, дату публикации, ключевые навыки и описание.

## Структура данных

| Поле | Описание | Примечания |
|---|---|---|
| `id` | Уникальный идентификатор вакансии | Есть дубликаты с разной датой публикации |
| `technology` | Технологическое направление | Например: «1C аналитик», «Python», «SQL» |
| `name` | Название вакансии | Текстовое |
| `company` | Название компании | Текстовое |
| `city` | Город размещения | Текстовое |
| `salary_display` | Отображение зарплаты | «Не указана», если зарплата не указана |
| `salary_from` | Нижняя граница зарплаты | 0 — если не указана |
| `salary_to` | Верхняя граница зарплаты | 0 — если не указана |
| `salary_currency` | Валюта зарплаты | Пустая строка, если зарплата не указана |
| `experience` | Требуемый опыт | Например: «От 1 года до 3 лет» |
| `employment` | Тип занятости | Например: «Полная занятость» |
| `schedule` | Рабочий график | Например: «Полный день», «Удалённая работа» |
| `published` | Дата и время публикации | Формат: ДД.ММ.ГГГГ ЧЧ:ММ |
| `key_skills` | Ключевые навыки | Через запятую |
| `description` | Описание вакансии | Текст вакансии |

## Особенности набора данных

- В наборе есть дубликаты по полю `id`, которые различаются временем публикации и, возможно, другими полями.
- Повторные строки могут означать повторные публикации одной вакансии.
- Null-значения представлены нулями в числовых полях, пустыми строками в текстовых полях или значением «Не указана» в поле `salary_display`.

## Задание 1.3. Обработка пропусков в зарплатах

1. Добавьте вспомогательный столбец `salary_filled`.
2. Столбец должен показывать, указана ли зарплата.
3. Значение должно быть `1`, если хотя бы одно из полей `salary_from` или `salary_to` заполнено.
4. Значение должно быть `0`, если оба поля равны нулю.

Пример формулы:

```excel
=IF(OR([@salary_from]>0,[@salary_to]>0),1,0)
```

5. Добавьте столбец `salary_avg`.
6. В этом столбце должна рассчитываться средняя зарплата для вакансий, где хотя бы одна граница указана.

Формула должна:

- рассчитывать среднее, если указаны обе границы;
- подставлять одну границу, если другая равна нулю;
- оставлять пустое значение, если зарплата не указана.

Пример формулы:

```excel
=IF(AND([@salary_from]>0,[@salary_to]>0),AVERAGE([@salary_from],[@salary_to]),IF([@salary_from]>0,[@salary_from],IF([@salary_to]>0,[@salary_to],"")))
```

## Задание 2.5. Поиск зарплаты по id с помощью XLOOKUP

**Цель:** отработать современную альтернативу `VLOOKUP` — функцию `XLOOKUP` для поиска по `id` вакансии.

На листе `Summary` создайте небольшой блок **«Поиск по id вакансии»**.

Пример структуры:

| Поле | Значение |
|---|---|
| id вакансии | пользователь вводит id вручную |
| Название | формула |
| Город | формула |
| Средняя зарплата | формула |

Формулы:

```excel
=XLOOKUP($M$2,Clean_Data[id],Clean_Data[name],"Нет данных")
```

```excel
=XLOOKUP($M$2,Clean_Data[id],Clean_Data[city],"Нет данных")
```

```excel
=LET(x,XLOOKUP($M$2,Clean_Data[id],Clean_Data[salary_avg],""),IF(x="","Нет данных",x))
```

Проверьте работу блока, введя несколько `id` из таблицы.

Кратко объясните, почему `XLOOKUP` удобнее `VLOOKUP` именно на этом наборе данных.

Пример ответа:

> `XLOOKUP` удобнее, потому что не нужно указывать номер столбца, как в `VLOOKUP`. Формула становится проще, а при добавлении или удалении столбцов продолжает работать без изменений.
